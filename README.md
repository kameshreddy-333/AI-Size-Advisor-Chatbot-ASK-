# AI Size Advisor Chatbot

## 📌 Overview
This project is a domain-specific AI chatbot for e-commerce that provides clothing size recommendations using Google Gemini API.

## 🚀 Features
- Product browsing
- Size recommendation
- AI chatbot (domain restricted)
- Collections feature

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Flask (Python)
- API: Google Gemini

## ▶️ Run Project
```bash
pip install -r requirements.txt
python app.py
